# Regra: liberar a votação (história 7)

- **Quem libera:** só o facilitador, que é quem criou a sala.
- **O que muda na tela:** depois de definir a história, as cartas ficam bloqueadas com a mensagem "Aguardando o facilitador liberar a votação". O botão "Liberar votação" aparece só para o facilitador. Ao clicar, as cartas liberam para todos ao mesmo tempo.
- **O que acontece com os votos já dados:** não existe voto antes de liberar. Depois de liberada, os votos continuam ocultos até o facilitador revelar. "Nova rodada" apaga os votos e volta a bloquear a votação.

## Como conferir (Gustavo, à mão no site)
1. Sala nova: as cartas estão bloqueadas para todos.
2. Quem não é o facilitador não vê o botão.
3. O facilitador clica em Liberar e as cartas liberam para todos.
4. Votar, revelar e abrir nova rodada: a votação volta bloqueada e sem votos antigos.
